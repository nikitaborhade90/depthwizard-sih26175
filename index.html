Production architecture

This prototype runs a classical shadow-and-shading estimator entirely in the browser so the pipeline is inspectable end to end. In deployment, stage 3 is served by a fine-tuned Depth Anything V2 model behind FastAPI:

POST /v1/dsm
  image, crs?, gcp[]?
→ rdsm.tif, dsm.tif, conf.tif

Everything downstream of stage 3 — calibration, meshing, flood and slope analysis — is the same code path in both modes.

3 · Depth estimation

Shadow length gives object height; shading gradient along the sun vector gives the terrain trend. Azimuth is read from image metadata in the georeferenced path — set it by hand for plain PNG/JPG.

4 · Metric calibration

Transform—

Scale-and-shift fit: H = a·d + b, with a from the relief between reference anchors and b from the coarse DEM. Ground control points refine both when available.
